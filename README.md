## 🚀 Como Subir no GitHub e Vercel com Git

### Passo 1: Inicializar o Git (se ainda não fez)
Abra o terminal nesta pasta (`projeto10-restaurante-rida`) e execute:
```bash
git init
git add .
git commit -m "feat: lancamento Le Petit Bleu Bistro RIDA"
git branch -M main
```

### Passo 2: Vincular ao seu Repositório do GitHub
Crie um novo repositório vazio no seu [GitHub](https://github.com/new) chamado `le-petit-bleu-restaurante` e vincule com os comandos:
```bash
git remote add origin https://github.com/SEU-USUARIO/le-petit-bleu-restaurante.git
git push -u origin main
```

### Passo 3: Deploy Automático na Vercel
1. Acesse o painel da [Vercel](https://vercel.com/new).
2. Clique em **"Add New Project"** e selecione o repositório `le-petit-bleu-restaurante`.
3. As configurações já estão pré-configuradas no `vercel.json`:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Clique em **Deploy**. Em menos de 1 minuto seu site estará online com HTTPS gratuito!
